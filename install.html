DailyDash 앱 설치

하늘향 매출 장부를 홈 화면에 추가하면 앱처럼 한 번에 열리고, 주소창 없이 넓은 화면으로 쓸 수 있어요.

설치 방법 보기 지금 앱으로 실행 중이에요
바로 실행홈 화면 아이콘을 누르면 앱처럼 바로 열려요.
자동 업데이트스토어 없이 항상 최신 버전으로 열려요.
안전한 보관입력한 내역은 가게 서버에 저장되고 매일 백업돼요.
아이폰 · 아이패드이 기기
  1. Safari 로 이 페이지를 열어 주세요. (iOS 16.4 이상은 Chrome 에서도 가능해요)
  2. 화면 아래(아이패드는 위)의 공유 버튼 을 누르세요.
  3. 목록을 내려 홈 화면에 추가 를 고르세요.
  4. 오른쪽 위 추가를 누르면 끝! 홈 화면의 DailyDash 아이콘으로 실행하세요.
안드로이드 (Chrome · 삼성 인터넷)이 기기
  1. 위의 앱 설치하기 버튼을 누르세요. 버튼이 안 보이면 다음 단계로 진행하세요.
  2. 브라우저 오른쪽 위(삼성 인터넷은 아래) ⋮ 메뉴를 여세요.
  3. 앱 설치 또는 홈 화면에 추가를 누르세요.
  4. 설치가 끝나면 홈 화면과 앱 목록에 DailyDash 가 생겨요.
PC (Chrome · Edge)이 기기
  1. 위의 앱 설치하기 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘을 누르세요.
  2. 설치를 누르면 바탕 화면과 시작 메뉴에 DailyDash 가 생겨요.

휴대폰으로 열기

휴대폰 카메라로 QR 코드를 비추면 이 설치 안내가 열려요. 직원분들께 링크를 보내도 돼요.

자주 묻는 질문

앱스토어 · 플레이스토어에는 없나요?

DailyDash 는 웹 앱(PWA)이라 스토어를 거치지 않고 이 페이지에서 바로 설치해요. 용량이 작고, 따로 업데이트할 필요도 없어요.

업데이트는 어떻게 하나요?

새 버전이 나오면 앱을 열 때 자동으로 받아요. 화면 아래에 "새 버전이 준비됐어요" 가 보이면 새로고침을 눌러 주세요.

입력한 데이터는 휴대폰에 저장되나요?

아니요. 모든 내역은 가게 서버에 저장되고 매일 자동 백업돼요. 휴대폰을 바꿔도 로그인만 하면 그대로예요.

설치 버튼이 안 보여요.

이미 설치되어 있거나, 브라우저가 버튼 설치를 지원하지 않는 경우예요. 위의 기기별 설치 방법을 따라 해 주세요. 아이폰은 공유 메뉴의 "홈 화면에 추가" 로 설치해요.

앱을 지우려면?

홈 화면의 DailyDash 아이콘을 길게 눌러 삭제하면 돼요. 서버의 데이터는 그대로 남아 있어요.
