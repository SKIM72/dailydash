아이폰 · 아이패드이 기기
  1. Safari 로 이 페이지를 열어 주세요. (iOS 16.4 이상은 Chrome 에서도 가능해요)
  2. 화면 아래(아이패드는 위)의 공유 버튼 을 누르세요.
  3. 목록을 내려 홈 화면에 추가 를 고르세요.
  4. 오른쪽 위 추가를 누르면 끝! 홈 화면의 DailyDash 아이콘으로 실행하세요.
안드로이드 (APK 앱)이 기기

APK 받기
  1. APK 받기를 누르세요. "유해할 수 있는 파일" 안내가 나오면 다운로드를 누르세요.
  2. 다운로드가 끝나면 알림이나 내 파일 › 다운로드에서 받은 파일을 여세요.
  3. "출처를 알 수 없는 앱" 안내가 나오면 설정 › 이 출처 허용을 켜고 뒤로 돌아오세요.
  4. 설치를 누르세요. Play 프로텍트 안내가 나오면 세부정보 › 무시하고 설치를 누르세요.
  5. 홈 화면의 DailyDash 아이콘으로 열고 로그인하면 끝!

APK 없이 브라우저로 설치하려면

  1. Chrome 오른쪽 위(삼성 인터넷은 아래) ⋮ 메뉴를 여세요.
  2. 앱 설치 또는 홈 화면에 추가를 누르세요.
PC (Chrome · Edge)이 기기
  1. 위의 앱 설치하기 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘을 누르세요.
  2. 설치를 누르면 바탕 화면과 시작 메뉴에 DailyDash 가 생겨요.

휴대폰으로 열기

휴대폰 카메라로 QR 코드를 비추면 이 페이지가 열리고, 안드로이드는 바로 앱을 받을 수 있어요. 직원분들께 링크를 보내도 돼요.

자주 묻는 질문

앱스토어 · 플레이스토어에는 없나요?

하늘향 전용 앱이라 스토어에 올리지 않았어요. 안드로이드는 이 페이지에서 APK 를 받아 설치하고, 아이폰은 Safari 의 "홈 화면에 추가" 로 설치해요.

APK 를 설치할 때 경고가 나와요. 괜찮나요?

플레이스토어 밖에서 받은 앱에는 항상 나오는 안내예요. 이 페이지에서 받은 파일은 하늘향 서명 키로 서명되어 있어요. 다른 곳에서 받은 "DailyDash" 파일은 설치하지 마세요.

업데이트는 어떻게 하나요?

안드로이드 앱과 홈 화면 앱 모두 화면을 서버에서 불러오기 때문에, 새 기능은 앱을 열 때 자동으로 받아요. 화면 아래에 "새 버전이 준비됐어요" 가 보이면 새로고침을 눌러 주세요. APK 파일을 다시 받아야 하는 경우는 드물고, 그때는 이 페이지에 새 버전이 표시돼요.

입력한 데이터는 휴대폰에 저장되나요?

아니요. 모든 내역은 가게 서버에 저장되고 매일 자동 백업돼요. 휴대폰을 바꿔도 로그인만 하면 그대로예요.

설치 버튼이 안 보여요.

이미 설치되어 있거나, 브라우저가 버튼 설치를 지원하지 않는 경우예요. 위의 기기별 설치 방법을 따라 해 주세요. 아이폰은 공유 메뉴의 "홈 화면에 추가" 로 설치해요.

앱 위쪽에 주소창이 보여요.

안드로이드 앱은 휴대폰의 Chrome 으로 화면을 띄워요. Chrome 이 꺼져 있거나 오래된 버전이면 주소창이 보일 수 있어요. 플레이스토어에서 Chrome 을 최신으로 업데이트한 뒤 앱을 다시 열어 주세요.

앱을 지우려면?

홈 화면의 DailyDash 아이콘을 길게 눌러 삭제(또는 앱 정보 › 제거)하면 돼요. 서버의 데이터는 그대로 남아 있어요.
