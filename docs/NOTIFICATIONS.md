# 마감 입력 알림 (웹 푸시)

정한 시각까지 **오늘 입력된 내역이 하나도 없으면** 휴대폰(또는 PC)으로 알림을 보냅니다.
같은 날에는 한 번만 보내고, 이미 입력했으면 보내지 않습니다.

## 켜는 방법 (직원 각자, 기기마다)

1. DailyDash 앱에서 **마이페이지 → 화면 설정 → 마감 입력 알림** 을 켭니다.
2. 알림 허용 창이 뜨면 **허용** 을 누릅니다.
3. 알림 시각(17:00 ~ 23:30)을 고르고 **시험 알림 보내기** 로 잘 오는지 확인합니다.

| 기기 | 조건 |
| --- | --- |
| 안드로이드 앱(APK) | 1.1.0 이상. 1.0.0 을 쓰고 있다면 앱 다운로드 페이지에서 새로 받아 덮어 설치합니다. |
| 안드로이드 Chrome · PC Chrome/Edge | 브라우저 알림 허용 |
| 아이폰 · 아이패드 | iOS 16.4 이상, Safari 에서 "홈 화면에 추가"한 앱으로 열었을 때만 |

## 서버 쪽

- 알림 서명 키(VAPID)는 서버가 처음 시작할 때 만들어 DB(`app_settings`)에 보관합니다. 따로 설정할 것은 없습니다.
  (원하면 `.env` 에 `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` 로 직접 지정할 수 있습니다)
- 서버는 5분마다 알림 시각이 지난 기기를 확인합니다. 알림을 끄거나 앱을 지운 기기는 자동으로 정리됩니다.
- 키를 바꾸면 기존 구독이 모두 무효가 되므로, 직원들이 알림을 다시 켜야 합니다.
