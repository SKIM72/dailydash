# AI 월간 리포트 (Google Gemini)

월간 요약 화면 아래의 **AI 월간 리포트**는 그달 매출을 Google Gemini 가 읽고 사장님께 보고하듯 정리해 주는 기능입니다.

- **숫자는 서버가 계산하고, AI 는 해석만 씁니다.** 매출·증감률은 DB 에서 직접 집계해 넘기므로 AI 가 숫자를 지어내지 않습니다.
- **만들기는 관리자만**, 보기는 승인된 계정 모두 가능합니다.
- 만든 리포트는 DB(`ai_reports`)에 저장됩니다. 데이터가 바뀌지 않았으면 다시 눌러도 AI 를 부르지 않고 저장본을 보여 줍니다. (무료 사용량 절약)
- 관리자 한 명당 10분에 5번까지 만들 수 있습니다.
- **매월 자동 생성**: 매월 1~5일 오전 6시 이후, 지난달을 마감 기준으로 정리한 리포트가 없으면 서버가 스스로 만듭니다.
  (Gemini 가 붐비면 30분 뒤 다시 시도) 작업 이력에는 `system (자동)` 으로 남습니다.

## Google 로 보내는 내용

| 보냄 | 보내지 않음 |
| --- | --- |
| 그달·비교 기간의 매출·현금·카드·지출 합계, 영업일 수, 증감률 | 비고(이름 등)·특기사항 |
| 최근 24개월 월매출, 요일별 평균, 일별 매출 | 계정 이메일 등 개인정보 |
| 품목(적요) 이름과 품목별 매출 | 건별 상세 내역 |

> **무료 등급 주의**: Google 은 무료 등급으로 보낸 내용을 서비스 개선에 쓸 수 있고, 사람이 검토할 수도 있다고 안내합니다.
> 이것이 부담되면 Google Cloud 에 결제를 연결한 프로젝트의 키(유료 등급)를 쓰면 됩니다. 유료 등급은 개선에 쓰지 않습니다.

## 켜는 방법

1. [Google AI Studio → API 키](https://aistudio.google.com/apikey) 에 Google 계정으로 들어가 **API 키 만들기**를 누릅니다.
   결제를 연결하지 않은 프로젝트의 키는 무료 등급입니다.
2. 서버 `~/dailydash/.env` 맨 아래에 키를 넣습니다. (다른 사람에게 보이지 않게 `chmod 600 .env` 유지)
   ```
   GEMINI_API_KEY=발급받은키
   ```
3. 앱만 다시 시작합니다.
   ```bash
   cd ~/dailydash
   docker compose up -d app
   docker compose logs --tail 20 app   # "[ai] AI 월간 리포트 사용" 이 보이면 성공
   ```

끄려면 `GEMINI_API_KEY=` 를 비우고 같은 명령으로 다시 시작합니다.

기본 모델은 `gemini-3.8-flash` 입니다. 무료 등급은 Google 쪽이 붐비거나(503) 한도(429)에 걸리는 일이 잦아서,
붐비면 몇 초 뒤 자동으로 다시 시도하고, 그래도 안 되면 가벼운 예비 모델 `gemini-3.5-flash-lite` 로 넘어갑니다. (무료 한도는 모델마다 따로)
바꾸려면 `.env` 에 `GEMINI_MODEL=` / `GEMINI_FALLBACK_MODEL=` 을 넣습니다.

## 문제 해결

| 화면 안내 | 원인 · 해결 |
| --- | --- |
| Gemini 서버가 지금 붐빕니다 | Google 쪽 일시적인 혼잡입니다. 자동 재시도와 예비 모델까지 실패한 경우라 몇 분 뒤 다시 시도합니다. |
| Gemini 무료 사용량 한도에 걸렸습니다 | 분당/하루 무료 한도를 넘었습니다. 잠시 뒤(또는 다음 날) 다시 시도합니다. 한도는 [AI Studio 사용량 페이지](https://aistudio.google.com/rate-limit)에서 확인합니다. |
| Gemini API 키가 올바르지 않습니다 | `.env` 의 키가 틀렸거나 삭제된 키입니다. 새 키로 바꾸고 앱을 다시 시작합니다. |
| AI 응답을 읽지 못했습니다 | 일시적인 응답 오류입니다. 다시 시도합니다. 계속되면 `docker compose logs app` 의 `[ai]` 줄을 확인합니다. |
